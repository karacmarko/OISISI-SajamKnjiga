# OISISI - Informacioni sistem uprave sajma knjiga

Projekat iz predmeta Osnovi informacionih sistema i softverskog inženjerstva.

## Autor projekta
* **Marko Karać** (RA 14/2023) — samostalna izrada projekta.

## Struktura rešenja
* `Core` — modeli podataka, serijalizacija, DAO sloj i poslovna logika.
* `ConsoleClient` — konzolna aplikacija.
* `WpfClient` — grafički korisnički interfejs.
